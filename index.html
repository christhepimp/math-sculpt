Math Sculpt

Pure mathematics · starts as a square clay box

Everything is math. No brushes. No mouse sculpting.

x y z = original vertex of the square box
t = time (seconds) · Math = full Math object

Y mode: formula returns a number → added to Y
Vector mode: formula returns [nx, ny, nz] → absolute new position

Example vector: [x, y + Math.sin(x*4)*0.2, z]

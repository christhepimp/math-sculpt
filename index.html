Math Sculpt

Addressable mathematical clay — every grain is a number

grains: —

Each vertex is a numbered grain (i = 0 … n-1). You can push any grain in any direction with math. Writing the formula that turns the box into a precise human (or any complex object) is the hard part — the math framework allows it in theory, but the formula itself becomes extremely complex.

Addressable clay
x y z = original position of the grain
i = grain index (0 to n-1)
n = total number of grains
t = time · Math = full Math object

Return [nx, ny, nz] to move that grain anywhere in 3D space.
Color: return [r, g, b] in 0–1.

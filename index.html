Math Sculpt

Geometry + color defined entirely by mathematics

Max subdivision 128 ≈ 100k+ triangles. Higher values approach dense procedural detail but will stress the browser. Unreal/Nanite-level density is not possible in pure client-side Three.js from a single box — this is the practical ceiling for real-time pure-math sculpting in the browser.

Everything is math.
x y z = original box vertex · t = time · Math = full Math

Geometry: number (Y) or [nx,ny,nz]
Color: must return [r, g, b] in 0–1 range
